# STAC pilot over the OME 2024 NGFF challenge data


An exploration of the [STAC specification](https://stacspec.org/) applied to the [OME 2024 NGFF challenge data](https://ome.github.io/ome-ngff-challenge-2024/).

Using also [Portolan](https://www.portolan-sdi.org/)-like metadata where it fits.

This is not a formal STAC implementation, but rather a pilot to explore the possibilities of using STAC for this type of bio data.

Some metadata is forced to fit some STAC (e.g. sham coordinates). It is an experiment. Please do not use this for production.

This is NOT geodata, but we are using STAC to explore its potential for bio data.
